# Customer_behavior_analysis
🛍️ Customer Shopping Behavior Analysis

A data analytics project that explores customer purchasing patterns, their behavior in e-commerce, and actionable business insights using PostgreSQL, Python, Pandas, Power BI, and Visualization dashboards.

📊 Project Overview

This project analyzes customer behavior such as:

Top contributing customer segments

Repeat purchase frequency

Revenue distribution by age group and gender

Product category trends

Purchase journey patterns

The goal is to help businesses understand:
✔ Who their customers are
✔ What they buy
✔ How they behave over time
